# SPARE PRO - Wholesale Reseller Platform

SPARE PRO is a modern wholesale and dropshipping e-commerce platform built for resellers, featuring high-margin products across four core categories:

- **Gadgets**: Active noise-cancelling earbuds, magnetic power banks, and tech accessories.
- **Watches**: Luxury automatic chronographs and AMOLED smartwatches.
- **Footwear**: Performance athletic runners and artisan Chelsea boots.
- **Fashion**: Heavyweight French terry streetwear hoodies and selvedge denim trucker jackets.

---

## Key Features

- **Smooth, Modern & Premium Product Scrolling**:
  - Touch and mouse drag-to-scroll support with momentum physics.
  - Interactive navigation controls with live gradient progress tracking.
  - View mode switcher: Instant toggle between **Horizontal Slider** and **Grid View**.
  - Margin & wholesale pricing tags with strike-through retail MSRP.
- **Continuous Seamless Ticker Animation**: Hardware-accelerated infinite marquee highlighting wholesale perks.
- **Complete Reseller Workflow**:
  - Live Cart with item counter and quantity management.
  - Wishlist system with real-time feedback.
  - Quick View modal for rapid product inspection.
  - Toast notification engine.
  - Full catalog filtering by category.
- **Responsive Design**: Polished layout for desktop, tablet, and mobile.

---

## Tech Stack

- **Framework**: React 18
- **Tooling**: Vite
- **Routing**: React Router DOM (v6)
- **Styling**: Vanilla CSS3 (Custom Design System) + Bootstrap 5
- **Icons**: FontAwesome 6

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone git@github.com:mohammedfalaah/dropshipping_resellers.git

# Navigate into the project folder
cd dropshipping_resellers

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be running at `http://localhost:5173/`.

### Production Build

```bash
npm run build
npm run preview
```
